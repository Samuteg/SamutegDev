# Plano de Implementação — Redesign Aetherial Modern

Aplicar o design system "Aetherial Modern" (de `docs/blog_imgs/`) a **todas as páginas** do blog, mantendo a arquitetura Astro + CSS vanilla (sem Tailwind), com Manrope como fonte display.

## Decisões confirmadas
- **CSS**: estender os tokens de custom properties existentes + adicionar classes utilitárias (`.glass-card`, `.glow-hover`, etc.)
- **Layout base**: criar `BaseLayout.astro` para eliminar a duplicação de `<html>/<head>/Header/Footer`
- **Fonte display**: trocar Space Grotesk → Manrope (já confirmado em pergunta anterior)
- **Escopo**: todas as páginas (index, blog/index, blog post, about, obrigado-comentario)

## Fase 1 — Design tokens & utilitários (`global.css`)
- **Adicionar Manrope** via `@font-face` (baixar woff2 para `src/assets/fonts/manrope/`)
- **Trocar** `--font-display: "Space Grotesk"` → `"Manrope"` em `:root`
- **Alinhar tokens dark** com o DESIGN.md: `--accent-color` → `#cebdff` (primary), adicionar `--accent-secondary` (`#bdc2ff` periwinkle), `--accent-tertiary` (`#ffafd3` pink)
- **Adicionar tokens de elevação** (glassmorphism):
  ```
  --glass-bg: rgba(19,19,24,0.6)
  --glass-border: rgba(255,255,255,0.1)
  --glass-blur: 12px
  --glow-violet: rgba(206,189,255,0.05)
  ```
- **Adicionar classes utilitárias**: `.glass-card`, `.glow-hover`, `.label-caps` (mono, uppercase, letter-spacing 0.1em), `.section-divider` (linha violeta)
- **Tipografia**: mapear escala do DESIGN.md (display-lg 64px/800, headline-md 32px/700, body-lg 18px/1.7)
- **Manter light theme** funcionando (atualizar tokens light em paralelo)

- **Animações**: o reference usa IntersectionObserver para scroll-reveal. O projeto já tem `fade-in-up` com animation-delay — estender esse sistema ao invés de duplicar
- **Light theme**: manter funcionando (não quebrar o toggle existente)
- **Content Collection**: não mexer na estrutura de posts markdown, apenas no layout
- **Acessibilidade**: manter `aria-expanded` no header, contrastes AA nos textos
- **Build verification**: rodar `astro build` ao final de cada fase para validar
